
# Python-Websocket

## About The Project

This is a real-time chat application built with Python using WebSockets. It enables users to join chat rooms and exchange messages instantly. The project is lightweight, scalable, and can be deployed on any cloud provider.

## Overview

This real-time chat application demonstrates how to use WebSockets in Python for instant messaging. It includes features like room-based chats, connection management, and user presence handling.

## Features

<div>
  <ul>
      <li> <b>Real-Time Messaging:</b> Send and receive messages instantly using WebSockets.</li>
      <li> <b>Multiple Rooms:</b> Users can join specific rooms and chat with others in the same room.</li>
      <li> <b>Connection Management:</b> Handle user connections and disconnections gracefully.</li>
  </ul>
</div>

## Getting Started

## Prerequisites

Before you begin, make sure you have the following tools installed on your machine:

- **Python 3.12.7 or higher** - [Download Python](https://www.python.org/downloads/)

If you don't have any of these tools installed, follow the provided links to install them.


## Installation

1.- Clone the repository

   ```sh
   git clone https://github.com/Retrofiyer/Websocket-Python.git
   cd Websocket-Python
   ```
2.- Create a virtual environment

 ```sh
    python -m venv .venv
    source .venv/bin/activate   # On Windows, use `.venv\Scripts\activate`
   ```
3.- Install dependencies

 ```sh
    pip install -r requirements.txt
   ```

## Running the service

  ```sh
    python run.py
   ```

Open any browser and type

```sh
    localhost:8000 or 127.0.0.1:8000
   ```
